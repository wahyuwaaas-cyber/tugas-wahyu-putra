Langkah-Langkah Collab Project GitHub


  1. Buka Github
  2. Masuk Repository
  3. Masuk setting
  4. Masuk collaborator
  5. Verfikasi kode yang masuk ke email
  6. Add people
  7. Masukan nama akun dan add people
  8. Buka gmail akun di collab kan
  9. Verifikasi akun yang meminta untuk nge invite
  10. Konfirmasi
  11. Buka laragon yang akan cloning project
  12. Buka terminal
  13. Pastikan masih ada folder www
  14. Ketik "git clone [code repository yang akan di clone]"enter
    • Cara menyalina kode,buka repository yang akan di clone,pencet code,salin code
  15. Masuk ke folder yang sudah
  16. Ketik [cd nama_folder_cloning]
  17. Pastikan di samping nama folder [www] sudah terdapat nama folder yang sudah di cloning
  18. Ketik [code .] untuk membuka vs code secara otomatis

  • Jika buletan pada kode [ul,li] hilang, maka hapus di css yang merupakan select universal[*{}]
